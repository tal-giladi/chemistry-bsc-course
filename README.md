# Self-taught Chemistry Degree — Technion B.Sc. track

A part-time, hands-on self-study course that follows the Technion B.Sc. in Chemistry course by course: maths, physics and Python bridges, then general, analytical, physical, organic, inorganic and biological chemistry, with every wet lab rebuilt as an interactive simulation, real published data and safe kitchen experiments.

This is a self-study course, not a degree: it does not award an academic degree or any licence, and it does not train hands-on bench skills with real reagents. Lesson 01.1 explains exactly what it does and does not give you.

## How it works

- 33 modules over three "years", about 10–12 hours a week. See the [course map](COURSE-MAP.md).
- Every lesson ends in something you do: a simulation with a target result, a Python analysis, a real-spectrum exercise, a safe home experiment or a problem set with worked answers.
- Every lesson has a short quiz and every module has a module quiz (pass mark 70%).
- Lab code and data for each module are in `labs/module-NN/`. Install the Python tools once with [labs/common/requirements.txt](labs/common/requirements.txt).
- Interactive lab simulations: [simulations](simulations/README.md).

## Safety

Home experiments use kitchen and pharmacy materials only. Do not buy laboratory reagents: in Israel many chemicals need a permit under the Hazardous Substances Law 1993, and a home has no fume hood. Read [01.4 · Chemical safety](lessons/module-01/lesson-04.md) before any hands-on work.

## Sources
