# Module 25 plan — Analytical Chemistry Lab 2

Technion: 01240214 Analytical Chemistry Lab 2 (plan.md S7): UV-Vis of mixtures, fluorescence (quinine), atomic absorption and emission, GC and GC-MS, HPLC, cyclic voltammetry.
Depth: a third-year instrumental lab. Module 19 taught the theory of each instrument; this module runs them as a lab: the procedure, why each step, the safety reasoning, what goes wrong, and the data with its error. Each lesson = simulation run (built later) + Python analysis in `labs/module-25/` + a safe home experiment where plan.md lists one + a short pencil set.
Builds on: 03.1 (Beer–Lambert for mixtures as a linear system), 09.4 (calibration, LOD, Harvey eq. 5.12), 09.6 (phone-photo pseudo-absorbance, sRGB linearisation), 19.1–19.5 (instrument theory), 23.3 (spectrophotometric practice, blanks, corrections), 17.1 (EI mass spectra).
Simulations (outline §5, built later): spectrometer `mixture` (25.1), `fluorescence` (25.2), `aas` (25.3); chromatography `gc`, `temperature-program` (25.4), `hplc`, `overlap` (25.5); voltammetry `scan-rate`, `quasi` (25.6).
Home experiments exactly as plan.md S7: cardboard + DVD phone spectrometer and food-dye Beer–Lambert (25.1); tonic water under a UV flashlight, with a dilution and table-salt quenching series (25.2, WARNING: never look into UV light); the same spectrometer on a fluorescent lamp and a pinch of table salt in a gas-hob flame (25.3, flame WARNING, no methanol "rainbow" tests). 25.4–25.6 have no home part (instruments only): simulation, Python, NIST WebBook, pencil.
Module practical: 25.6 Part C — a quality-control dossier for a bitter-lemon soft drink: tartrazine by UV-Vis, quinine by fluorescence standard addition against the 21 CFR 172.575 limit, flavour identity by GC-MS match + retention index, vitamin C by voltammetric standard addition; each result with an expanded uncertainty and a pass/fail decision, written on the lab-report template.

Data: all committed CSVs are simulated by `labs/module-25/make_data.py` (seeded, true values in the file header). NIST mass spectra are NOT committed (the collection is copyrighted, all rights reserved): `get_nist_ms.py` downloads them for personal use into the git-ignored `data/downloaded/` and builds the simulated GC-MS run from them. Retention indices quoted are medians of DB-5-type ramped entries read from the NIST WebBook on 2026-10-17. No SDBS numbers anywhere.
Safety: 25.1 cutting a DVD (sharp edges; adult with scissors); 25.2 UV flashlight WARNING (never look into it or at reflections; never at people or pets; 365 nm preferred); 25.3 flame WARNING (gas hob only, a pinch of salt from a spoon, no methanol or alcohol flames, tie hair back, nothing flammable nearby); nothing tasted after it has been used in an experiment.
