- **research question** — a question answered by a number or a yes/no, with a named population and an independent reference to compare with (lessons/module-33/lesson-01.md)
- **feasibility check** — testing a planned project for available, licensed data; working tools; safety; and hours before committing to it (lessons/module-33/lesson-01.md)
- **attended time** — the time you yourself spend on each item of a study, as opposed to machine time while a calculation runs unattended (lessons/module-33/lesson-01.md)
- **rerun factor** — the multiplier on planned work that allows for items that must be done again; about 1.3 for a first project (lessons/module-33/lesson-01.md)
- **known-answer test** — reproducing a published value with your method before trusting its new results (lessons/module-33/lesson-02.md)
- **pilot study** — a small run of the whole procedure on a few items to find slow steps and estimate the scatter (lessons/module-33/lesson-02.md)
- **held-out set** — data kept aside and never used for fitting, so that a model's error can be measured on items it has not seen (lessons/module-33/lesson-02.md)
- **analysis plan** — the result to report, the allowed exclusions and the deciding test, written before the main data are seen (lessons/module-33/lesson-02.md)
- **data dictionary** — a file describing every data file and column of a project: source, licence, date, units and changes (lessons/module-33/lesson-02.md)
- **FAIR principles** — guidelines that research data be Findable, Accessible, Interoperable and Reusable (Wilkinson et al. 2016) (lessons/module-33/lesson-02.md)
- **abstract** — a self-contained summary of a report in about five sentences: context, gap, what was done, result with uncertainty, meaning (lessons/module-33/lesson-03.md)
- **limitations section** — the part of a report that names what the data, the method and the setting cannot show, and what would remove each limit (lessons/module-33/lesson-03.md)
- **A0** — the ISO 216 paper size of 841 × 1189 mm (1 m²), the common size for scientific posters; A4 is one quarter of it in each direction (lessons/module-33/lesson-03.md)
- **peer review** — a structured critique of a piece of work by someone at a similar level, ending in a clear recommendation (lessons/module-33/lesson-04.md)
- **ORCID iD** — a free, persistent identifier that links a researcher to their outputs (lessons/module-33/lesson-04.md)
- **DOI (digital object identifier)** — a persistent identifier for a publication, data set or other research output; Zenodo assigns one to each record (lessons/module-33/lesson-04.md)
- **preprint** — a manuscript made public before formal peer review, for example on ChemRxiv (lessons/module-33/lesson-04.md)
