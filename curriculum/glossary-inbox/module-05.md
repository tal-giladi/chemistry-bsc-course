- **interpreter** — the program (python) that reads a script and runs it line by line (lessons/module-05/lesson-01.md)
- **package** — reusable code written by others and loaded with import, such as numpy or pandas (lessons/module-05/lesson-01.md)
- **PyPI** — the Python Package Index, the public store from which pip installs packages (lessons/module-05/lesson-01.md)
- **virtual environment** — a project folder with its own set of installed packages, isolated from every other project (lessons/module-05/lesson-01.md)
- **pin** — an exact package version written as name==version, so everyone installs the same code (lessons/module-05/lesson-01.md)
- **requirements file** — a text list of pins that pip installs with pip install -r (lessons/module-05/lesson-01.md)
- **semantic versioning** — the major.minor.patch scheme in which the size of the change tells you the risk of upgrading (lessons/module-05/lesson-01.md)
- **deprecated** — announced as going away in a future release; still works for now but should not be used in new code (lessons/module-05/lesson-01.md)
- **array** — a numpy grid of numbers of one type, described by its shape and dtype (lessons/module-05/lesson-02.md)
- **vectorisation** — writing a calculation as one expression on whole arrays instead of a loop over elements (lessons/module-05/lesson-02.md)
- **broadcasting** — numpy's rule for combining arrays of different shapes by stretching axes of length 1 (lessons/module-05/lesson-02.md)
- **boolean mask** — an array of True/False values that selects elements of another array (lessons/module-05/lesson-02.md)
- **Maxwell–Boltzmann distribution** — the distribution of molecular speeds in a gas at temperature T (lessons/module-05/lesson-02.md)
- **residual** — measured value minus model value for one data point (lessons/module-05/lesson-03.md)
- **least squares** — fitting by choosing parameters that minimise the sum of squared (weighted) residuals (lessons/module-05/lesson-03.md)
- **chi-square** — the sum of squared residuals each divided by its standard uncertainty (lessons/module-05/lesson-03.md)
- **reduced chi-square** — chi-square divided by the degrees of freedom; near 1 when the residuals match the stated noise (lessons/module-05/lesson-03.md)
- **covariance matrix** — the matrix of parameter variances (diagonal) and covariances (off-diagonal) returned by a fit (lessons/module-05/lesson-03.md)
- **weighted fit** — a fit in which each point counts in inverse proportion to its variance (lessons/module-05/lesson-03.md)
- **DataFrame** — a pandas table of named columns, each with one data type (lessons/module-05/lesson-04.md)
- **JCAMP-DX** — a labelled plain-text format for exchanging spectra, defined for IR in 1988 and extended to other techniques (lessons/module-05/lesson-04.md)
- **AFFN** — ASCII free-format numeric, the uncompressed number form in JCAMP-DX data lines (lessons/module-05/lesson-04.md)
- **YFACTOR** — the JCAMP-DX scale factor that turns the stored integers into real y values (lessons/module-05/lesson-04.md)
- **notebook** — a document of markdown and code cells whose code runs in a kernel and shows its output inline (lessons/module-05/lesson-05.md)
- **kernel** — the background Python process that runs a notebook's cells and keeps their variables (lessons/module-05/lesson-05.md)
- **hidden state** — variables in the kernel's memory that no longer match the cells on the page (lessons/module-05/lesson-05.md)
- **pooled standard deviation** — the square root of the mean variance of several groups measured the same way; a steadier noise estimate than any one group (lessons/module-05/lesson-05.md)
