- **matrix** — a rectangular table of numbers; multiplying it by a vector turns a set of linear equations into one equation, E c = A (lessons/module-03/lesson-01.md)
- **determinant** — for a 2×2 matrix, ad − bc; a linear system has exactly one solution when it is not zero (lessons/module-03/lesson-01.md)
- **Cramer's rule** — solving a small linear system by ratios of determinants (lessons/module-03/lesson-01.md)
- **null space** — all vectors a matrix sends to zero; for a composition matrix it holds the balancing coefficients of a reaction (lessons/module-03/lesson-01.md)
- **rank** — the number of truly independent rows of a matrix (lessons/module-03/lesson-01.md)
- **condition number** — how much a linear system can amplify relative errors in its data; near 1 is good, large means ill-conditioned (lessons/module-03/lesson-01.md)
- **least squares** — choosing the unknowns that minimise the sum of squared differences when there are more equations than unknowns (lessons/module-03/lesson-01.md)
- **eigenvalue** — a number λ with A v = λ v for some non-zero vector v; the roots of det(A − λI) = 0 (lessons/module-03/lesson-02.md)
- **eigenvector** — a non-zero vector that a matrix only stretches, A v = λ v; in chemistry an orbital's coefficients or a vibration's shape (lessons/module-03/lesson-02.md)
- **characteristic equation** — det(A − λI) = 0 for a matrix, or m r² + b r + k = 0 for an oscillator; its roots give eigenvalues or exponential rates (lessons/module-03/lesson-02.md)
- **Hückel theory** — a simple model of π electrons with orbital energies E = α + xβ, x the eigenvalues of the connection matrix (lessons/module-03/lesson-02.md)
- **delocalization energy** — the extra π stabilisation of a conjugated molecule compared with isolated double bonds, in units of β (lessons/module-03/lesson-02.md)
- **normal mode** — a vibration in which all atoms move at one frequency; an eigenvector of the mass-weighted force-constant matrix (lessons/module-03/lesson-02.md)
- **ordinary differential equation (ODE)** — an equation for a function of one variable that contains its derivatives, such as dc/dt = −k cⁿ (lessons/module-03/lesson-03.md)
- **separation of variables** — solving dy/dt = f(y) g(t) by moving all y terms to one side and integrating both sides (lessons/module-03/lesson-03.md)
- **integrated rate law** — the concentration as a function of time obtained by solving a rate law (lessons/module-03/lesson-03.md)
- **Euler's method** — stepping an ODE forward with c[i+1] = c[i] + h f(t[i], c[i]); its error is proportional to the step h (lessons/module-03/lesson-03.md)
- **steady state** — the value at which dc/dt = 0; for dc/dt = r − k c it is r/k (lessons/module-03/lesson-03.md)
- **stiff system** — a set of ODEs with very different time scales, which needs an implicit solver (lessons/module-03/lesson-03.md)
- **damped harmonic oscillator** — m x″ + b x′ + k x = 0; under-, critically or overdamped depending on b² − 4mk (lessons/module-03/lesson-04.md)
- **critical damping** — b = 2√(mk), the fastest return to rest without overshoot (lessons/module-03/lesson-04.md)
- **quality factor (Q)** — ω0/(2γ), a measure of how many oscillations happen before the motion dies out (lessons/module-03/lesson-04.md)
- **reduced mass** — μ = m1 m2/(m1 + m2), the effective mass of two bodies vibrating against each other (lessons/module-03/lesson-04.md)
- **force constant** — the stiffness k of a bond or spring in N/m; for a diatomic k = μ(2πc ωe)² (lessons/module-03/lesson-04.md)
- **consecutive reactions** — steps in series, A → B → C, in which an intermediate rises, peaks and falls (lessons/module-03/lesson-05.md)
- **rate matrix** — the matrix K in dc/dt = K c for a network of first-order steps; its eigenvalues are the decay rates (lessons/module-03/lesson-05.md)
- **matrix exponential** — e^(Kt), the solution operator of dc/dt = K c, computed from eigenvectors or with scipy.linalg.expm (lessons/module-03/lesson-05.md)
- **steady-state approximation** — setting d[intermediate]/dt ≈ 0 when the intermediate is removed much faster than it forms (lessons/module-03/lesson-05.md)
- **rate-determining step** — the slow step that sets the overall rate of a multi-step reaction (lessons/module-03/lesson-05.md)
- **Bateman function** — the difference of two exponentials describing an intermediate in A → B → C, used for drug absorption and elimination (lessons/module-03/lesson-05.md)
