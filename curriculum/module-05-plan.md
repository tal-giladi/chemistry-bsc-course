# Module 05 plan — Python for Scientists

Technion: 02340128 Introduction to Computer Science and Python (bridge scope only: what the chemistry modules need). Depth: MIT OCW 6.100L (Ana Bell, Fall 2022); Software Carpentry "Plotting and Programming in Python".
Simulations: none. Labs: `labs/module-05/` (all packages from `labs/common/requirements.txt`: Python 3.14, numpy 2.5.4, scipy 1.18.1, matplotlib 3.11.2, pandas 3.0.6, jupyterlab 4.6.4, uncertainties 3.2.3, lmfit 1.3.4; checked 2026-10-16).
Module practical: lesson 05.5 Part B, the plan 1.7 task as a reproducible notebook: read a raw instrument export, fit a straight line with uncertainty, check residuals, predict an unknown with its uncertainty, record versions, pass "restart and run all".

| Lesson | Objectives (short) | Prerequisites | Hands-on | Sources to verify |
|---|---|---|---|---|
| 05.1 Setup and the scientific stack | Install Python 3.14 (install manager), make a venv, install the pinned requirements, verify versions; write a first script with a dict, a function and f-strings | 01.2 | `check_setup.py` (pins vs installed), `lesson01_molar_mass.py` (molar masses from a formula dict, IUPAC atomic weights) | python.org downloads (3.14.8, 3.15.0, install manager 26.4); docs.python.org Windows guide; PyPI pins; IUPAC CIAAW |

| 05.3 Fitting with uncertainty | Fit a line with polyfit/curve_fit and read the covariance; choose absolute_sigma; judge a fit by residuals and reduced chi-square; propagate to an unknown with uncertainties | 05.2, 01.2, 02.5 | `lesson03_fitting.py`: dye calibration line + unknown; weighted first-order decay fit; lmfit comparison | SciPy 1.18 curve_fit; NIST/SEMATECH e-Handbook 4.4.4; uncertainties docs; lmfit 1.3.4 docs |

| 05.5 Reproducible notebooks | Run JupyterLab; avoid hidden state; relative paths, seeds, version record; pass restart-and-run-all; module practical | 05.1–05.4 | `lesson05_report.ipynb` (template) + `lesson05_report_solution.py`; data `density_export.csv` or the learner's Module 1 data | Sandve et al. 2013; JupyterLab 4.6 docs |

Data: all CSV and JCAMP files in the lab are generated by `labs/module-05/make_data.py` (seeded; model values in the file). NIST WebBook spectra are not redistributed (the data compilation is "all rights reserved"); learners download one with `fetch_nist_ir.py` into the git-ignored `data/downloaded/`.
