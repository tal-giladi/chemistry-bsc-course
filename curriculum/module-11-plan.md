# Module 11 plan — Scientific English: Reading and Writing Chemistry

Planning file, not imported. Written 2026-10-17. Technion: 03240033 Advanced Technical English B (reading academic texts, summarising, writing). Course plan 2.8: "if your English is already strong, replace with reading one review article a week" — this module turns that into three skills a chemist uses every week: reading a paper fast and critically, finding and judging sources and data, and writing a report with figures that carry the result.
Simulations linked: none (outline §5 lists none for this module).
Labs: `labs/module-11/` (numpy, matplotlib; Python 3.14, pins in `labs/common/requirements.txt`; `doi_check.py` uses only the standard library and the public Crossref REST API, with an offline cache).
Module practical: lesson 11.3 Part C — rewrite a deliberately bad figure of the class vinegar data (`bad_figure.py` → `good_figure.py`), then write the full lab report of the 10.6 vinegar project (or the 09.6 calibration) with the lab report template and the self-check list; plus the paper summary of 11.1 as the reading half of the practical.
