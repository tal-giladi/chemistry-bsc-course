# Lab report self-check (lesson 11.3)

Use with `templates/lab-report.md`. Tick each line before you call a report finished. Read the report once on paper, slowly, as someone who was not there.

## The result

- [ ] The aim is one or two sentences and names the quantity measured.
- [ ] The final result appears in the abstract and the conclusion as value ± uncertainty, unit, with the meaning of "±" (for example "95 % CI" or "expanded uncertainty, k = 2").
- [ ] The number of digits matches the uncertainty (lesson 01.2).
- [ ] The result is compared with a reference or label value, and the comparison says whether the difference is inside the uncertainty.

## The text

- [ ] Each paragraph makes one point, stated in its first sentence.
- [ ] Methods are in the past tense and complete enough to repeat; accepted facts are in the present tense.
- [ ] Every term is defined on first use; every abbreviation is spelled out once.
- [ ] Claims are as strong as the evidence: "shows" only where the data show it; "suggests" or "may" where they do not.
- [ ] The discussion names the largest source of uncertainty, how you know, and one concrete improvement.
- [ ] The report says what a home or simulated version could not show compared with a real lab.

## Figures and tables

- [ ] Each figure has one message, and its caption (or title) states that message as a sentence.
- [ ] Every axis and column header reads "quantity / unit".
- [ ] Small data sets (n below about 20) are shown as points, not only as bars.
- [ ] Error bars are defined in the caption (SD, SE or CI, and n).
- [ ] A bar chart starts at zero; a dot plot may zoom in.
- [ ] Colours are readable in greyscale and by colour-blind readers; no rainbow (jet) colour map.
- [ ] Nothing on the figure is decoration: no 3D, no heavy grid, no legend that repeats the axis labels.
- [ ] Every figure and table is referred to in the text, in number order.

## Sources

- [ ] Every value not measured by you has a source, as close to the measurement as possible, with the date checked for online sources (lesson 11.2).
- [ ] Every DOI resolves and none is retracted.
