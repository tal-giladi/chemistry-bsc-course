# Module 32 labs — Electives: Electrochemistry and Solid State

Python analyses for the module: Tafel analysis of hydrogen evolution, corrosion rates from polarisation curves, indexing a real powder X-ray pattern, bands and intrinsic carriers, and the module practical (a materials dossier). Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs need only numpy, scipy and matplotlib. Keep `ec32.py` (constants and helpers) in the same folder as the scripts, and run each script from this folder, for example `py lesson01_tafel.py`.

Your own data:

```bash
py lesson01_tafel.py my_curve.csv 3.1
py lesson02_corrosion.py inhibited 1.0
py lesson03_xrd.py my_pattern.csv
```

The Tafel file needs the columns `electrode,E_V,i_A_cm2` and the second argument is the uncompensated resistance in ohm (for a 1 cm² electrode). The XRD file needs `two_theta_deg,counts` measured with a copper tube.

## Home experiment

Lesson 32.2 has one: nails in salt water with copper wire, aluminium foil and a galvanised nail (kitchen salt and hardware only). Lesson 32.4 has an optional cold-LED test with the low-voltage circuit of Lesson 04.5. Read the WARNING boxes first. Never open, puncture, crush, heat or short-circuit a battery. Hydrogen evolution in sulfuric acid, steel in hydrochloric acid, X-ray tubes and cadmium oxide (fatal if inhaled, carcinogenic) are lab-only; this folder needs no chemicals.

## Data and sources

- `cdo_xrd.csv`, `in2o3_xrd.csv`, `cdo_in2o3_xrd.csv`: REAL powder XRD data from Dahiya H., Dahiya B. and Sabarwal S. (2026), Raw powder X-ray diffraction (XRD) data for GCN, CdO, In2O3, CdO-In2O3, CdO-In2O3-GCN, Zenodo, https://doi.org/10.5281/zenodo.18522088, licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Changes: the files CdO.xy, In2O3.xy and CdO-In2O3.asc were converted to CSV with a comment header; no values were changed. `get_zenodo_xrd.py` downloads the originals and repeats the conversion. The record does not state the wavelength; the header of CdO-In2O3.asc records a Rigaku MiniFlex with a Cu target, Kα 1.54059/1.54441 Å and no filter. Retrieved 2026-10-17.
- Reference structures: Crystallography Open Database entries 9006671 (CdO, a = 4.6963 Å), 2310009 (In2O3, a = 10.117 Å) and 8104161 (CdIn2O4, a = 9.166 Å), https://www.crystallography.net/cod/, checked 2026-10-17.
- `tafel_her.csv`, `corrosion_steel.csv`: GENERATED by `make_data.py` (seeded; run `py make_data.py` to rebuild). Butler–Volmer and mixed-potential models with uncompensated resistance and noise; exchange current densities chosen inside the published spread for Ni and Cu (Trasatti 1972; Nørskov et al. 2005).
- Constants in `ec32.py`: CODATA 2022 via NIST (https://physics.nist.gov/cuu/Constants/); Cu Kα₁, Kα₂ and Kβ wavelengths from the NIST X-ray Transition Energies Database. Semiconductor parameters in `lesson04_bands*.py`: Ioffe Institute NSM archive (http://www.ioffe.ru/SVA/NSM/Semicond/). Corrosion-rate conversion: ASTM G102-23.

## What these labs do not train

They do not run a potentiostat, polish an electrode, handle acids or operate a diffractometer. The electrochemical data are generated, so they have no drifting surfaces, bubbles or reference-electrode problems. The XRD patterns are real but come without an instrument standard, so peak widths give only lower limits of crystallite size.
