# Module 15 labs — Organic Chemistry 1: Structure and Reactions

Small Python exercises, one per lesson, built on RDKit, the free open-source cheminformatics library. RDKit reads SMILES, finds functional groups, assigns R/S and E/Z, builds 3D conformers with the MMFF94 force field and applies reaction rules. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17 with RDKit 2026.9.1, numpy 2.5 and matplotlib 3.11):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. Run each file from this folder, for example `py lesson01_groups.py`. Keep `org15.py` in the same folder.

For the 3D model parts of the lessons use [MolView](https://molview.org/) in a browser (free, no installation) or Avogadro 2.0.0 (free, BSD licence, released 2026-04-01, [documentation](https://two.avogadro.cc/docs/)).

Shared: `org15.py` holds the gas constant (CODATA 2022), a small CSV reader, `canon()` for canonical SMILES and the RDKit check.

The module practical checker stores only hashes of the canonical answers, so running it does not reveal them. The hashes depend on how RDKit writes canonical SMILES; with an RDKit version other than 2026.9.1 a correct answer could be reported as wrong. If that happens, compare with `py lesson07_practical_solution.py`.

## Data

- `molecules.csv`: SMILES of 17 compounds from PubChem (PUG REST, property "SMILES"), with their CIDs, accessed 2026-10-17. PubChem data are free to use.
- `pka_table.csv`: pKa values in water. HCl, HNO₃, acetic acid, HCN, water (15.7) and ethanol from OpenStax Organic Chemistry (McMurry, 2023) section 2.8; ethyne, ammonia, ethene and methane from section 9.7; phenol 9.99 (CID 996), acetone 20 (CID 180) and ammonia pKb 4.751 (CID 222, giving NH₄⁺ 9.25) from PubChem; carbonic acid Ka1 4.3 × 10⁻⁷ from OpenStax Chemistry 2e Appendix H; H₃O⁺ −1.7 as the textbook convention. All accessed 2026-10-17.
- `butenes_nist.csv`: gas-phase ΔfH° at 298.15 K of 1-butene, (Z)- and (E)-2-butene and 2-methylpropene from the NIST Chemistry WebBook (Prosen, Maron and Rossini, J. Res. NBS 46 (1951) 106), https://webbook.nist.gov/, accessed 2026-10-17 (US government work).
- `sn_runs.csv`: generated by `make_data.py` (seed 1505) from two rate laws with illustrative rate constants; these are not measurements.
- `practical_answers.csv`: the answer sheet for the module practical; fill in the `smiles` column.
