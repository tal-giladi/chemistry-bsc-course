# Module 4 labs — Physics for Chemists

Small Python exercises, one per lesson, plus three home measurements (a pendulum, a resistor network and the LED module practical). Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy and matplotlib.

Run each file from this folder, for example `py lesson01_morse.py`.

| Lesson | Exercise | Solution | Data |
|---|---|---|---|
| 04.1 Forces and energy | `lesson01_morse.py` | `lesson01_morse_solution.py` | HCl constants in the code (NIST WebBook; Hu et al. 2003) |
| 04.2 Oscillations | `lesson02_pendulum.py` | `lesson02_pendulum_solution.py` | `pendulum_example.csv` or your own (`L_m,trial,t20_s`) |
| 04.3 Electrostatics | `lesson03_coulomb.py` | `lesson03_coulomb_solution.py` | constants in the code (CODATA 2022; NIST NaCl bond length) |
| 04.4 Circuits | `lesson04_network.py` | `lesson04_network_solution.py` | `network_example.csv` or your own (`quantity,value,note`) |
| 04.5 Light and photons (module practical) | `lesson05_led_planck.py` | `lesson05_led_planck_solution.py` | `led_example.csv` or your own (`led,lambda_nm,R_ohm,V_led_V,V_res_V`) |

To run on your own measurements, pass the CSV file as the first argument:

```bash
py lesson02_pendulum.py my_pendulum.csv
py lesson04_network.py my_network.csv
py lesson05_led_planck.py my_leds.csv
```

## Home equipment (lessons 04.2, 04.4, 04.5)

String, a bunch of keys, a tape measure; a breadboard, 2 or 3 AA cells in a holder, 0.25 W resistors (150, 220, 330, 470 ohm and 1 kohm), a 1 kohm potentiometer, four 5 mm LEDs of different colours with known wavelengths, jumper wires and a cheap digital multimeter. Battery power only; read the safety box in each lesson first.

## Data

- `pendulum_example.csv`, `network_example.csv` and `led_example.csv` are generated by `make_data.py` from known models with a fixed random seed (the models and true parameters are in that file). They are realistic but not measured, so you can check your answers against the true values.
- HCl: r_e and omega_e from the NIST Chemistry WebBook, https://webbook.nist.gov/cgi/cbook.cgi?ID=C7647010&Mask=1000, accessed 2026-10-16; D0 = 35748.2 cm^-1 from Hu, Melville and Hepburn, J. Chem. Phys. 119, 8938 (2003).
- NaCl gas-phase bond length 0.2360795 nm from the NIST Chemistry WebBook, https://webbook.nist.gov/cgi/cbook.cgi?ID=C7647145&Mask=1000, accessed 2026-10-16.
- Constants: CODATA 2022 via NIST, https://physics.nist.gov/cuu/Constants/.
