# Module 3 labs — Linear Algebra and Differential Equations

Small Python exercises, one per lesson. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy, scipy and matplotlib.

Run each file from this folder, for example `py lesson01_linear.py`.

| Lesson | Exercise | Solution | Data |
|---|---|---|---|
| 03.1 Linear systems | `lesson01_linear.py` | `lesson01_linear_solution.py` | `mixture_absorbance.csv` |
| 03.2 Eigenvalues | `lesson02_eigen.py` | `lesson02_eigen_solution.py` | none (CO2 wavenumbers from NIST CCCBDB in the code) |
| 03.3 First-order ODEs | `lesson03_ode.py` | `lesson03_ode_solution.py` | `order_test.csv` |
| 03.4 Oscillators | `lesson04_oscillator.py` | `lesson04_oscillator_solution.py` | `pendulum_example.csv` or your own CSV |
| 03.5 Consecutive reactions (module practical) | `lesson05_consecutive.py` | `lesson05_consecutive_solution.py` | `consecutive_example.csv` |

## Data

- `mixture_absorbance.csv`, `order_test.csv`, `pendulum_example.csv` and `consecutive_example.csv` are generated by `make_data.py` from known models with a fixed random seed (parameters are in that file). They are realistic but not measured, so you can check your answers against the true model values. The dye absorptivities are illustrative, not real food dyes.
- Constants in the code: CO2 vibrational wavenumbers from the NIST CCCBDB (https://cccbdb.nist.gov/exp2x.asp?casno=124389&charge=0), the H35Cl harmonic wavenumber from the NIST Chemistry WebBook (https://webbook.nist.gov/cgi/cbook.cgi?ID=C7647010&Mask=1000), atomic masses from NIST, and the atomic mass constant from CODATA 2022; all accessed 2026-10-16.
- For lesson 03.4, record your own pendulum and save it as a CSV with the header `swings,t_s,amplitude_cm`. Then run:

```bash
py lesson04_oscillator.py my_pendulum.csv
```
