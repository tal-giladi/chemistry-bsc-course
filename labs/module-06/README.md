# Module 6 labs — Biology for Chemists

Small Python exercises, one or two per lesson, plus three home experiments (potato osmosis, DNA from strawberries and the yeast fermentation of the module practical). Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder and downloaded structures to `data/downloaded/` (both ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy and matplotlib; `fetch_pdb.py` uses the standard library and an internet connection.

Run each file from this folder, for example `py lesson01_osmosis.py`.

| Lesson | Exercise | Solution | Data |
|---|---|---|---|
| 06.1 Cells and membranes | `lesson01_osmosis.py` | `lesson01_osmosis_solution.py` | `osmosis_example.csv` or your own (`c_NaCl_M,strip,m_before_g,m_after_g`) |
| 06.2 Proteins | `lesson02_proteins.py` | `lesson02_proteins_solution.py` | `ubiquitin_1UBQ.pdb`, or any PDB file from `fetch_pdb.py` |

To run on your own measurements or structures, pass the file as the first argument:

```bash
py lesson01_osmosis.py my_potato.csv
py fetch_pdb.py 4HHB
py lesson02_proteins.py data/downloaded/4HHB.pdb
py lesson04_atp_budget.py my_bottles.csv
```

## Home materials (lessons 06.1, 06.3, 06.4)

A raw potato, table salt, strawberries, washing-up liquid, pharmacy alcohol (70 % ethanol or isopropyl, chilled), table sugar, dry baker's yeast, two 500 mL plastic bottles, cotton wool, cups, a 20 mL oral syringe and a scale (a 0.01 g or 0.1 g pocket scale is best). Kitchen and pharmacy materials only; read the safety box in each lesson first.

## Data

- `osmosis_example.csv` and `fermentation_example.csv` are generated by `make_data.py` from known models with a fixed random seed (the models and true parameters are in that file). They are realistic but not measured, so you can check your answers against the true values.
- `ubiquitin_1UBQ.pdb` is the protein part of PDB entry 1UBQ (Vijay-Kumar, Bugg and Cook, J. Mol. Biol. 194, 531, 1987), downloaded from https://files.rcsb.org/download/1UBQ.pdb on 2026-10-16, waters removed. PDB archive data are CC0 1.0 (https://www.wwpdb.org/about/usage-policies).
- `ubiquitin_designed.fasta` is a designed coding sequence for human ubiquitin (UniProt P0CG48, residues 1–76) with one common human codon per amino acid and a TGA stop. It is not a natural gene.
- Constants: CODATA 2022 via NIST (https://physics.nist.gov/cuu/Constants/). pKa values: EMBOSS iep table. Ion concentrations: PhysiologyWeb typical mammalian values. ATP and glucose free energies: OpenStax Biology 2e and eQuilibrator; ethanol, CO2 and water: OpenStax Chemistry 2e Appendix G.
