# Module 10 labs — Analytical Chemistry Lab 1

Python exercises for each lesson, the home experiments (syringe drop calibration, baking soda heated to constant mass, a soap-lather hardness test) and the module practical: five mass-based vinegar titrations with an indicator blank and a full uncertainty budget. Each exercise file has two functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs need numpy, scipy (only `make_data.py`) and matplotlib.

Run each file from this folder, for example `py lesson01_indicator.py`.

| Lesson | Exercise | Solution | Data |
|---|---|---|---|
| 10.1 Titration bench | `lesson01_indicator.py` | `lesson01_indicator_solution.py` | `drop_calibration_example.csv` or your own (`trial,n_drops,m_before_g,m_after_g`) |
| 10.2 Potentiometric and redox | `lesson02_potentiometric.py` | `lesson02_potentiometric_solution.py` | `potentiometric_example.csv` (`V_mL,pH`), `redox_example.csv` (`V_mL,E_mV`) |
| 10.3 Precipitation and EDTA | `lesson03_complex.py` | `lesson03_complex_solution.py` | constants in the file |
| 10.4 Gravimetry and coulometry | `lesson04_gravimetry.py` | `lesson04_gravimetry_solution.py` | `oven_example.csv` or your own (`t_min,m_total_g`) |

To run on your own measurements, pass the file as the first argument (lesson 10.5 takes the ISE file first and the soap file second) and edit the setup constants at the top of the script (tray mass in 10.4; titrant, drop mass and label in 10.6):

```bash
py lesson01_indicator.py my_drops.csv
py lesson04_gravimetry.py my_oven.csv
py lesson05_ise.py fluoride_ise_example.csv my_soap.csv
py project_vinegar.py my_vinegar.csv
```

## Home materials

White vinegar (household, about 5 % acidity; never vinegar essence or cleaning vinegar); baking soda; a red cabbage for the indicator (lesson 08.4); three bottled waters with different calcium and magnesium on the label; pure liquid soap (castile-type, not detergent); a 10 mL and a 20 mL oral syringe (no needles); a dropper; a small screw-top jar; a small foil tray; a kitchen oven and oven mitts; a kitchen scale with 0.01 g resolution; cups; safety glasses; a tray. Kitchen and pharmacy materials only; read the safety box in each lesson first, and never mix vinegar or anything else with bleach.

## Data

- `drop_calibration_example.csv`, `potentiometric_example.csv`, `redox_example.csv`, `oven_example.csv`, `fluoride_ise_example.csv`, `soap_test_example.csv` and `vinegar_project_example.csv` are generated by `make_data.py` from known models with a fixed random seed (1010). The models and true values are in the docstrings of that file. They are realistic but not measured, so you can check your answers against the true values. Run `py make_data.py` to regenerate them.
- Constants: acetic acid pKa 4.757 (Harvey, Analytical Chemistry 2.1, Appendix 16.11); indicator pKa values (Harvey Table 9.2.3); Ksp values (Appendix 16.10); EDTA pKa values (section 9.3) and log Kf of CaY²⁻ 10.69 and MgY²⁻ 8.79 (Appendix 16.12); formal potentials Fe³⁺/Fe²⁺ 0.68 V and Ce⁴⁺/Ce³⁺ 1.44 V in 1 M H₂SO₄ (Appendix 16.13). Harvey: https://chem.libretexts.org/Bookshelves/Analytical_Chemistry/Analytical_Chemistry_2.1_by_David_Harvey/Analytical_Chemistry_2.1_(Harvey)
- Faraday constant F = 96 485.332 12 C/mol, CODATA 2022 via NIST (https://physics.nist.gov/cgi-bin/cuu/Value?f).
