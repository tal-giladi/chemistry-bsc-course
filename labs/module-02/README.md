# Module 2 labs — Calculus for Chemists

Small Python exercises, one per lesson. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy, scipy and matplotlib.

Run each file from this folder, for example `py lesson01_arrhenius.py`.

| Lesson | Exercise | Solution | Data |
|---|---|---|---|
| 02.1 Functions | `lesson01_arrhenius.py` | `lesson01_arrhenius_solution.py` | `arrhenius_rates.csv` |
| 02.2 Derivatives | `lesson02_rates.py` | `lesson02_rates_solution.py` | `decay_concentration.csv` |
| 02.3 Integrals | `lesson03_integrals.py` | `lesson03_integrals_solution.py` | `decay_concentration.csv`, NIST N2 Shomate coefficients in the code |

## Data

- `arrhenius_rates.csv`, `decay_concentration.csv`, `cooling_example.csv` are generated by `make_data.py` from known models with a fixed random seed (parameters are in that file). They are realistic but not measured, so you can check your answers against the true model values.
- The N2 heat-capacity coefficients are from the NIST Chemistry WebBook (nitrogen, gas-phase Shomate equation, 100–500 K), https://webbook.nist.gov/cgi/cbook.cgi?ID=C7727379&Mask=1, accessed 2026-10-16.
- For the module practical, record your own cooling curve and save it as a CSV with the header `t_s,T_C`. Then run:

```bash
py lesson05_cooling.py my_curve.csv 22.5 0.252
```

The three arguments are the file, the room temperature in °C and the water mass in kg.
