# Module 7 labs — Foundations of Chemistry A

Small Python exercises, one per lesson (lesson 07.3 is a pencil exercise), plus two home experiments: the vinegar and baking soda series of lesson 07.5 and the salt standard and food-colour dilution of the module practical, lesson 07.7. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy and matplotlib.

Run each file from this folder, for example `py lesson05_limiting.py`.

To run on your own measurements, pass the files as arguments:

```bash
py lesson05_limiting.py my_vinegar.csv 50
py lesson07_solutions.py my_salt.csv my_dilution.csv
```

The `50` is the vinegar volume per cup in mL.

## Home materials (lessons 07.5 and 07.7)

White food vinegar (4–6 % acidity), baking soda, non-iodised table salt, liquid food colouring, water, 12 tall plastic cups and six small clear cups, a bottle of 150 mL or more with a lid, oral syringes of 10 mL and 20 mL (no needles), a teaspoon, labels, safety glasses and a scale (a 0.1 g or 0.01 g pocket scale is best). Kitchen materials only; read the safety box in each lesson first. Never use concentrated or "cleaning" vinegar, and never do the vinegar reaction in a closed bottle.

## Data

- `ionization_energies.csv`: NIST Atomic Spectra Database, Ionization Energies form (https://physics.nist.gov/PhysRefData/ASD/ionEnergy.html), retrieved 2026-10-16. US government work, used with citation.
- `hydride_boiling_points.csv`: PubChem compound pages, "Boiling Point" section (CID per row), retrieved 2026-10-17.
- `co2_320K_nist.csv`: NIST Chemistry WebBook, Thermophysical Properties of Fluid Systems (https://webbook.nist.gov/chemistry/fluid/), CO2 isotherm at 320 K, retrieved 2026-10-17. US government work, used with citation.
- `vinegar_example.csv` is generated by `make_data.py` from a known model with a fixed random seed (true vinegar strength 5.0 % w/v, 88 % of the CO2 escaping). It is realistic but not measured, so you can check your answer against the true value.
- `salt_standard_example.csv` and `dilution_example.csv` are illustrative example readings, not a real run. The density of 5 % NaCl (1.034 g/mL at 20 °C) is from the Engineering ToolBox table (https://www.engineeringtoolbox.com/density-aqueous-solution-inorganic-sodium-salt-concentration-d_1957.html).
