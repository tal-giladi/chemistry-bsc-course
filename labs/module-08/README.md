# Module 8 labs — Foundations of Chemistry B

Small Python exercises, one or two per lesson, plus the home experiments (ice–salt freezing mixture, sparkling water, red-cabbage indicator, vitamin C with povidone-iodine, lemon and vinegar cells) and the module practical: coffee-cup calorimetry and a vinegar titration. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs need numpy, scipy and matplotlib.

Run each file from this folder, for example `py lesson01_hess.py`.

`thermo.py` is a shared helper that reads `thermo_data.csv`. To run on your own measurements, pass the file as the first argument and edit the masses in the script's setup block:

```bash
py lesson05_redox.py "MnO4^- + C2O4^2- + H^+ -> Mn^2+ + CO2 + H2O"
py lesson06_nernst.py my_cells.csv
py lesson07_calorimetry.py my_calorimetry.csv
py lesson07_titration.py my_titration.csv
```

## Home materials

Ice, table salt and sugar; sealed bottles of sparkling water; a red cabbage; white vinegar (5 % acidity); lemons; baking soda; hand soap; povidone-iodine 10 % antiseptic and plain 500 mg vitamin C tablets (pharmacy); cornflour; orange juice; galvanised nails and copper wire; a digital multimeter and resistors (from Module 4); two nesting foam cups with a lid; a digital kitchen thermometer; a kitchen scale (0.01 g pocket scale is best); 1 mL and 10 mL oral syringes; cups; safety glasses. Kitchen and pharmacy materials only; read the safety box in each lesson first, and never mix bleach with anything.

## Data

- `thermo_data.csv`: standard enthalpies and free energies of formation and standard entropies at 298.15 K and 1 bar from OpenStax Chemistry 2e, Appendix G (https://openstax.org/books/chemistry-2e/pages/g-standard-thermodynamic-properties-for-selected-substances), checked 2026-10-16. NaHCO₃(s) ΔfH° −950.8 kJ/mol is the NBS value quoted on Wikipedia (https://en.wikipedia.org/wiki/Sodium_bicarbonate).
- Weak-acid constants in `lesson04_ph*.py`: OpenStax Chemistry 2e Appendix H; CO₂ solubility from Sander's Henry's-law compilation (https://henrys-law.org/henry/casrn/124-38-9). Electrode potentials in `lesson06_nernst*.py`: OpenStax Chemistry 2e Appendix L.
- `lemon_cell_example.csv`, `calorimetry_example.csv` and `titration_example.csv` are generated by `make_data.py` from known models with a fixed random seed (the models and true parameters are in that file). They are realistic but not measured, so you can check your answers against the true values. Run `py make_data.py` to regenerate them.
- Constants: CODATA 2022 via NIST (https://physics.nist.gov/cuu/Constants/): R = 8.314462618 J/(mol K), F = 96 485.33212 C/mol.
