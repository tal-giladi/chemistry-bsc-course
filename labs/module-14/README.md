# Module 14 labs — Chemical Physics Lab: Oscillators and Signals

Small Python exercises, one per lesson, plus the home measurements they analyse: a phone on a spring, ringdowns, three coupled pendulums, a bottle's note and a battery-powered RLC circuit. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy, scipy and matplotlib. The phone app is phyphox (free, Android and iOS; version 1.2.1 checked 2026-10-17): https://phyphox.org/

Run each file from this folder, for example `py lesson01_spring.py`. Keep `phyphox_csv.py` in the same folder.

| Lesson | Exercise | Solution | Data |
|---|---|---|---|
| 14.1 Spring with your phone | `lesson01_spring.py` | `lesson01_spring_solution.py` | `spring_static_example.csv` (`mass_kg,length_m`), `spring_dynamic_example.csv` (`mass_kg,trial,period_s`) |
| 14.2 Damping and Q | `lesson02_damping.py` | `lesson02_damping_solution.py` | `ringdown_spring.csv`, `ringdown_card.csv`, `ringdown_band.csv` (phyphox-style exports) |

To run on your own measurements, pass your files as arguments. For phyphox exports, also give the column number of the axis you want (time is column 0):

```bash
py lesson01_spring.py my_static.csv my_dynamic.csv
py lesson02_damping.py my_spring.csv 3
py lesson03_modes.py my_pendulums.csv
py lesson05_fft.py my_recording.csv 1
py lesson06_rlc.py my_rlc.csv
```

Export from phyphox with "Comma-separated values" and a decimal point. Column names vary between experiments and app versions; the scripts use column positions only.

Safety: the spring and pendulum work uses light loads over cushions; the RLC project uses battery or USB power only, never mains (see the warnings in lessons 14.1–14.6).

## Data

All CSV files here are example data generated by `make_data.py` (seeded; the true parameters are written in that file). They are realistic but not measured, so you can check your analysis against known answers before you trust it on your own data. Run `py make_data.py` to regenerate them.

- Spring: k = 24.0 N/m, spring mass 30 g, phone and bag 200 g.
- Ringdowns: Q = 110 (steel spring), 14.7 (with a cardboard disc), elastic band with a softening force (beta = -40 1/m^2), sampled at 100 Hz like a phone accelerometer.
- Coupled pendulums: L = 0.500 m, omega^2 = g/L + 1.60 (0, 1, 3) 1/s^2.
- RLC: L = 10.3 mH, C = 0.970 uF, R = 10.1 ohm, coil 33 ohm effective (28 ohm DC), f0 = 1593 Hz, Q = 2.39.
- CO2 constants in `lesson04_co2*.py`: fundamentals 1333, 667 and 2349 cm^-1 from the NIST CCCBDB (https://cccbdb.nist.gov/exp2x.asp?casno=124389), atomic masses from NIST and the atomic mass constant from CODATA 2022 (https://physics.nist.gov/cgi-bin/cuu/Value?u), all accessed 2026-10-17.
