# Module 30 labs — Physical Chemistry Lab 2

Python analyses for the four experiments of the module: the high-resolution HCl rotation-vibration spectrum, ESR hyperfine patterns of the methyl radical and the hydrogen atom, the speed of sound in a tube and the heat-capacity ratio of air (a real home experiment), and conjugated dyes as particles in a box. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs need only numpy, scipy and matplotlib. Keep `pc30.py` (constants and helpers) in the same folder as the scripts, and run each script from this folder, for example `py lesson01_hcl.py`.

Your own data for 30.3:

```bash
py lesson03_sound.py my_tube.csv 22.5 0.45 100.8 0.019
py lesson03_sound.py spectrum my_audio_spectrum.csv
```

The four numbers are air temperature (°C), relative humidity (0–1), pressure (kPa) and the tube's inner radius (m). The second command lists the resonance peaks of one phyphox Audio Spectrum export (first two columns: frequency, amplitude).

## Home experiment

Only lesson 30.3 has one: a tube closed at one end, a phone with phyphox (checked with 1.2.1) and a tape measure. Read the CAUTION box in the lesson first: moderate volume, careful cutting, keep the phone dry. Lesson 30.4 has an optional kitchen extension with carrot, tomato paste and cooking oil (no heating). HCl gas (30.1), ESR (30.2) and the cyanine dyes and methanol (30.4) are lab-only; this folder needs no chemicals.

## Data and sources

- `hcl_ftir_example.csv`, `esr_methyl_example.csv`, `esr_hydrogen_example.csv`, `tube_resonance_example.csv`, `audio_spectrum_example.csv`: GENERATED by `make_data.py` (seeded; run `py make_data.py` to rebuild). They are realistic, not measured. Model values: NIST Chemistry WebBook constants of H³⁵Cl (https://webbook.nist.gov/cgi/cbook.cgi?ID=C7647010&Mask=1000), isotope-scaled for H³⁷Cl; methyl radical g = 2.00255 and |a_H| = 2.304 mT (Fessenden and Schuler, J. Chem. Phys. 39, 2147, 1963); hydrogen hyperfine frequency 1420.405751768 MHz with exact Breit–Rabi fields; ideal moist air with γ(dry) = 1.4000 and the Levine–Schwinger end correction 0.6133 r.
- `cyanine_dyes.csv`: published absorption maxima with a source in each row (TCI products D4486 and C0426, Sigma-Aldrich 166510, Laidlaw 1970 via the Delta State University lab handout, OMLC PhotochemCAD β-carotene), retrieved 2026-10-17. Values vary by 2–6 nm between sources and solvents.
- Constants in `pc30.py`: CODATA 2022 via NIST (https://physics.nist.gov/cuu/Constants/); atomic masses from NIST Atomic Weights and Isotopic Compositions.

## What these labs do not train

They do not run an FTIR or ESR spectrometer or a UV-Vis instrument: no gas handling, cavity tuning or sample preparation. The HCl and ESR spectra are generated from published constants, so they carry no instrument artefacts beyond noise and line width. The sound experiment is real, with a phone in place of a signal generator and an oscilloscope.
