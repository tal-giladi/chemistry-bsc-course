# Module 16 labs — Organic Chemistry 2: Carbonyls, Aromatics and Synthesis

Python exercises with RDKit, product drills with hashed answer keys, one kitchen activity (Maillard browning on toast, lesson 16.6), and the module practical: two multi-step routes checked with a route checker (lesson 16.7). Each exercise file has functions marked TODO and an `ANSWERS` dictionary for the product drill; the matching `*_solution.py` file is the reference solution. No reagents are used anywhere in this module: all chemistry is on paper and on screen.

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs need RDKit 2026.9.1, numpy and scipy. Run each file from this folder, for example `py lesson01_oxidation.py`.

## The reaction library and route checker

`org16.py` is the shared helper. It holds a small library of about 25 textbook reactions written as RDKit reaction SMARTS (`REACTIONS`, each with the reagents it stands for), rules for aromatic directing effects, and a few classic incompatibilities (Grignard reagents with O–H, N–H or NO₂; Friedel–Crafts on deactivated rings or anilines; nitration of free anilines; Williamson with secondary or tertiary halides). `check_route` checks every step of a route, that each reactant is in `starting_materials.csv` or made earlier, and that the last product is the target. Structures are compared without stereochemistry.

It is a teaching model. It does not know yields, rates, conditions, solvents, purification or side products in the flask, and a route that passes is not a validated procedure. Each step applies one reaction at one site; repeat a step to react a second group.

Product drills store hashes of the canonical SMILES (`key()` in `org16.py`), so the answers are not readable in the exercise file; the worked answers are in each lesson's `<details>` blocks.

## Data and sources

- `starting_materials.csv`: the route checker's catalogue; names, PubChem CIDs and SMILES from PubChem (https://pubchem.ncbi.nlm.nih.gov/), accessed 2026-10-17.
- `amines_pka.csv`: conjugate-acid pKa values from OpenStax Organic Chemistry (2023), section 24.3 (https://openstax.org/books/organic-chemistry/pages/24-3-basicity-of-amines), accessed 2026-10-17.
- Carboxylic acid pKa values in `lesson03_acyl.py`: OpenStax 20.4 and PubChem aspirin (CID 2244, pKa 3.49). α-H pKa values in `lesson04_aldol.py`: OpenStax 22.5, Table 22.1. Hydration constants in `lesson02_addition.py`: orders of magnitude from OpenStax 19.5 and the textbook values quoted at https://en.wikipedia.org/wiki/Geminal_diol.
- Glucose SMILES in `lesson06_amines_sugars.py`: PubChem CIDs 79025 (α-D-glucopyranose), 64689 (β-D-glucopyranose), 107526 (open-chain D-glucose). Rotations +112.2, +18.7, +52.6 from OpenStax 25.5.
- `mutarotation_example.csv` is generated by `make_data.py` from a first-order model with a fixed random seed (illustrative rate constant 0.0120 min⁻¹, reading noise 0.3°). It is realistic but not measured. Run `py make_data.py` to regenerate it.
- Constants: CODATA 2022 via NIST (https://physics.nist.gov/cuu/Constants/): R = 8.314462618 J/(mol K).
