# Module 5 labs — Python for Scientists

One exercise per lesson. Each exercise file has functions (or notebook cells) marked TODO; the matching `*_solution.py` file is the reference solution. Figures and results are written to `runs/` in this folder (ignored by git).

## Setup

Python 3.14 and the packages pinned in `labs/common/requirements.txt` (numpy 2.5.4, scipy 1.18.1, matplotlib 3.11.2, pandas 3.0.6, jupyterlab 4.6.4, uncertainties 3.2.3, lmfit 1.3.4, rdkit 2026.9.1). Checked on 2026-10-16 with Python 3.14.3 on Windows 11; Python 3.14.8 is the current 3.14 release. From the repo root:

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
.venv\Scripts\python labs/module-05/check_setup.py
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. `check_setup.py` must end with `All good`.

Run each exercise from this folder, for example `..\..\.venv\Scripts\python lesson02_maxwell.py`.

## Data

- `calibration_dye.csv`, `dye_fading.csv`, `uvvis_export.csv`, `example_ir.jdx` and `density_raw.csv` are generated by `make_data.py` from known models with a fixed random seed (all parameters are in that file). They are realistic but not measured, so you can check your answers against the model values. The dye absorptivity and the IR spectrum are illustrative, not a real dye or compound.
- `density_raw.csv` uses sucrose densities at 20 °C from the reference table in `labs/module-01/reference_sucrose_density.csv` (smoothly interpolated for 5, 15 and 25 %), in the same raw format as the Module 1 practical.
- Atomic weights: IUPAC CIAAW abridged standard atomic weights 2024 (https://www.ciaaw.org/abridged-atomic-weights.htm). Constants: CODATA 2022 from NIST (https://physics.nist.gov/cuu/Constants/). Both accessed 2026-10-16.
- Real spectra: `fetch_nist_ir.py` downloads one IR spectrum in JCAMP-DX form from the NIST Chemistry WebBook (default: ethanol, gas phase, ID C64175) into `data/downloaded/`, which git ignores. The WebBook data compilation is copyright the U.S. Secretary of Commerce ("all rights reserved"), so these files are not stored in the repo; cite the WebBook when you use one. `py fetch_nist_ir.py --dry-run` shows the URL without downloading.
