# Module 23 labs — Physical Chemistry Lab 1

Small Python analyses, one per lesson, for the simulations and home experiments of the module: kinetic theory and the heat-capacity ratio of air, coffee-cup calorimetry, the FeSCN²⁺ equilibrium constant, food dye fading in dilute bleach, zinc–copper home cells and the Nernst slope, and surface tension of detergent solutions. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy, scipy and matplotlib. Keep `pc23.py` (shared constants and helpers) in the same folder as the scripts. For lesson 23.4 also copy `rgb_from_photos.py` from the Module 9 lab folder to read colours from your photos.

```bash
py lesson01_gases.py my_speeds.csv my_clement.csv
py lesson02_calorimetry.py my_calorimetry.csv
py lesson03_equilibrium.py my_fescn.csv
py lesson04_dye_fading.py my_dye_fading.csv
py lesson05_cells.py my_cells.csv

```

For 23.2 also edit the `SETUP` block (masses and fit windows) in the script.

Safety: the home experiments use kitchen and pharmacy materials only; read the warning at the top of each lesson's Hands-on section first. In particular, lesson 23.4 uses dilute household bleach: never mix bleach with acids (vinegar, citric acid, lemon) or ammonia, use small amounts, and keep the air moving. Do the citric acid calorimetry (23.2) and the bleach kinetics (23.4) on different days or after clearing everything away.

## Data

All CSV files here are example data generated by `make_data.py` (seeded; the true values are written in that file). They are realistic but not measured, so you can check your analysis against known answers before you trust it on your own data. Run `py make_data.py` to regenerate them.

- 23.1: 3000 argon speeds at 300 K; air with gamma = 1.400, 0.15 cm reading noise.
- 23.2: cup heat capacity 35 J/K (0.4 K lost while pouring the hot water, so the fit gives more); citric acid + NaHCO3 +34.7 kJ/mol with all CO2 gas, 92 % escaped; NaCl +3.9 kJ/mol, Epsom salt +14 kJ/mol. Formation enthalpies from OpenStax Chemistry 2e Appendix G (https://openstax.org/books/chemistry-2e/pages/g-standard-thermodynamic-properties-for-selected-substances); citric acid ionisation enthalpies from Goldberg et al., J. Phys. Chem. Ref. Data 31, 231 (2002), https://doi.org/10.1063/1.1416902; CO2 Henry's-law temperature dependence from the NIST WebBook (https://webbook.nist.gov/cgi/cbook.cgi?ID=C124389&Mask=10). Accessed 2026-10-17.
- 23.3: K = 140, eps*b = 4600 L/mol at 447 nm (illustrative values of the size teaching labs report).
- 23.4: k' = 3.0e-3 1/s for 2 mL bleach per 200 mL at 20 C, first order in hypochlorite, Ea = 50 kJ/mol (illustrative); photo noise 0.4 %.
- 23.5: lemon E = 0.93 V, r = 1.8 kOhm; 5 % salt water 0.78 V, 420 Ohm; vinegar 0.95 V, 950 Ohm; Nernst data ideal 2-electron slope with a 4 mV junction offset.
- 23.6: water at 21 C from IAPWS R1-76(2014) (https://iapws.org/relguide/Surf-H2O.html); Szyszkowski-type fall to a break at 1.5 mL/L.
- Constants: CODATA 2022 exact values (https://physics.nist.gov/cuu/Constants/), in `pc23.py`.
