# Module 27 labs — Electromagnetism and Matter

Small Python analyses, one per lesson: Gauss's law and the speed of light (with a microwave-oven home experiment), multipole moments from point charges, polarisabilities and dipole moments from real dielectric data, and intermolecular forces from measured molecular properties (the module practical). Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs only need numpy, scipy and matplotlib. Keep `pc27.py` (CODATA 2022 constants and helpers) in the same folder as the scripts.

| 27.1 Maxwell's equations | `lesson01_maxwell.py` | `lesson01_maxwell_solution.py` | `microwave_example.csv` (`trial,spacing_cm`), `liquids_nbs514.csv` |
| 27.2 Multipoles | `lesson02_multipoles.py` | `lesson02_multipoles_solution.py` | `water_tip3p.csv`, `co2_point_charges.csv`, `oh_minus_illustrative.csv` (`label,x_A,y_A,z_A,q_e`) |

Run each from this folder, for example `py lesson01_maxwell.py`. To use your own data:

```bash
py lesson01_maxwell.py my_microwave.csv 2450
py lesson02_multipoles.py hcl.csv
py lesson03_dielectrics.py my_debye_points.csv
py lesson04_imf.py 373
```

Safety: the only home experiment (27.1) uses a kitchen microwave oven in normal use. Read the warning in the lesson first: food only, no metal or foil, never run the oven empty, do not use an oven with a damaged door, and let hot food cool.

## Data

Real data (all retrieved and checked 2026-10-17; sources are also in each file's header):

- `reference_gases_nbs537.csv`: recommended dielectric constants of He, H₂, O₂, Ar, air, N₂, CO₂ at 20 °C and 1 atm from A. A. Maryott and F. Buckley, NBS Circular 537 (1953), section 2.2, https://nvlpubs.nist.gov/nistpubs/Legacy/circ/nbscircular537.pdf (US government work). Polarisability volumes from NIST CCCBDB, https://cccbdb.nist.gov/pollistx.asp.
- `liquids_nbs514.csv`: static permittivities at 20 °C of the NBS standard liquids from A. A. Maryott and E. R. Smith, NBS Circular 514 (1951), https://nvlpubs.nist.gov/nistpubs/Legacy/circ/nbscircular514.pdf; refractive index and density from PubChem (HSDB records, CID in the file); water density from the NIST WebBook fluid properties (IAPWS-95); gas dipoles from NIST CCCBDB.
- `debye_gases_nbs537.csv`: Debye fits (A, μ) for HCl, HBr, HI, NH₃, SO₂, H₂S, H₂O from NBS Circular 537, with modern Stark-effect dipoles from NIST CCCBDB, https://cccbdb.nist.gov/diplistx.asp.
- `imf_molecules.csv`: dipoles and polarisabilities from NIST CCCBDB, evaluated ionisation energies from the NIST Chemistry WebBook (ion energetics pages), boiling points from PubChem (hydrides, as in `labs/module-07/hydride_boiling_points.csv`) and the NIST WebBook (Ar, Kr, Xe, N₂, CCl₄).

Model parameters (generated by `make_data.py` from cited values):

- `water_tip3p.csv`: TIP3P charges and geometry (Jorgensen et al., J. Chem. Phys. 79, 926 (1983)), as listed in the LAMMPS manual, https://docs.lammps.org/Howto_tip3p.html.
- `co2_point_charges.csv`: EPM2 charges (Harris and Yung, J. Phys. Chem. 99, 12021 (1995)), https://towhee.sourceforge.net/forcefields/epm.html, on the experimental geometry r(CO) = 1.162 Å (NIST CCCBDB).
- `oh_minus_illustrative.csv`: illustrative charges for the origin exercise only; not a literature model.

Generated or reconstructed data (NOT measured):

- `microwave_example.csv`: example spot spacings for a 2450 MHz oven, true half-wavelength 6.118 cm, 0.3 cm reading noise.
- `hcl_debye_points.csv`: HCl gas (εr − 1) at 1 atm at eight temperatures, reconstructed from Zahn's 1924 Debye fit as listed in NBS Circular 537 (A = 7.63 cm³/mol, μ = 1.050 D) with 0.4 % noise. The original readings are not openly available; this file lets you run the full analysis and check that you recover the published fit.

Run `py make_data.py` to regenerate the model and example files (seeded).
