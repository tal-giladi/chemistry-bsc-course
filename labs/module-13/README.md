# Module 13 labs — Chemical Thermodynamics

Python exercises built on real NIST data, plus the home experiments (sealed syringe on a kitchen scale, rubber band, hot and cold water, boiling point against local pressure, salt water in the freezer) and the module practical: a thermodynamic data sheet for the water-gas shift and a freezing-point measurement of water activity (lesson 13.6). Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Plots are written to `runs/` in this folder (ignored by git).

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-16):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These labs need numpy, scipy and matplotlib. Run each file from this folder, for example `py lesson02_kirchhoff.py`.

`thermo13.py` is the shared helper: it reads `nist_shomate.csv` and gives $C_p(T)$, $H(T) - H(298.15)$, $S(T)$ and reaction $\Delta_r H$, $\Delta_r S$, $\Delta_r G$ and $K$. It refuses temperatures outside each NIST fit (water vapour starts at 500 K).

```bash
py lesson01_work.py my_syringe.csv
py lesson06_practical.py my_freezing.csv
```

## Home materials

A 10 mL plastic oral syringe with cap (or an eraser), a kitchen scale (up to 3 kg; a 0.01 g pocket scale for weighing salt), a ruler, a wide rubber band, mugs and plastic cups, a kettle and a saucepan, ice, table salt, a digital kitchen thermometer (0.1 °C display), a freezer, a phone (barometer app such as phyphox, if the phone has a pressure sensor), safety glasses. Kitchen materials only; read the safety box in each lesson first.

## Data and sources

- `nist_shomate.csv`: Shomate heat-capacity coefficients (A–H) for N₂, H₂, NH₃, CO, CO₂, H₂O(g) and H₂O(l) from the NIST Chemistry WebBook gas- and condensed-phase thermochemistry pages (https://webbook.nist.gov/chemistry/; source Chase 1998, NIST-JANAF), with the CODATA Key Values (Cox, Wagman and Medvedev 1984) of $\Delta_f H^\circ$ and $S^\circ$ at 298.15 K listed on the same pages. Retrieved 2026-10-17.
- `janaf_check.csv`: $\Delta_f G^\circ$ and $\log_{10}K_f$ of NH₃, CO, CO₂ and H₂O(g) from the NIST-JANAF tables online (https://janaf.nist.gov/, tables H-083, C-093, C-095, H-064), retrieved 2026-10-17. Used only to check the calculations.
- `antoine.csv` and `phase_data.csv`: Antoine coefficients, triple and critical points, transition enthalpies for water and CO₂ from the NIST WebBook phase-change pages (C7732185, C124389); water's triple point (611.657 Pa) and critical temperature (647.096 K) from IAPWS; $\Delta_\text{fus}H$ = 6.01 and $\Delta_\text{vap}H(373\ \text{K})$ = 40.67 kJ/mol from OpenStax Chemistry 2e 10.3. Ice and liquid water molar volumes from rounded densities (0.917 and 1.000 g/cm³).
- Benzoic acid 26.434 kJ/g: NIST SRM 39j certificate (https://tsapps.nist.gov/srmext/certificates/39J.pdf). Sucrose $\Delta_c H^\circ$ −5644 kJ/mol: NIST WebBook (C57501).
- `syringe_example.csv` and `freezing_example.csv` are generated by `make_data.py` from known models with a fixed random seed (Boyle's law with friction and a dead volume; a freezing model with supercooling and a +0.3 °C thermometer offset). They are realistic but not measured. Run `py make_data.py` to regenerate them.
- Constants: CODATA 2022 via NIST (https://physics.nist.gov/cuu/Constants/): R = 8.314462618 J/(mol K).
- NIST WebBook data are a U.S. government compilation and may be used with citation; the files here are small extracts.
