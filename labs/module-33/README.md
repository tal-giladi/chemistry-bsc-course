# Module 33 labs — Research Project

Small tools for running your 180-hour project: a project-folder generator, an hours budget with a feasibility check, a sample-size calculator, a poster-figure script and a final package check. Each exercise file has functions marked TODO; the matching `*_solution.py` file is the reference solution. Output goes to `runs/` in this folder (ignored by git). Your real project lives in its own folder outside the course repo.

Setup (once, Python 3.14, packages pinned in `labs/common/requirements.txt`; checked 2026-10-17):

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r labs/common/requirements.txt
```

On macOS or Linux use `python3.14` and `.venv/bin/python`. These scripts need only numpy, scipy and matplotlib. Run each one from this folder, for example `py lesson01_budget.py`. Run `py make_data.py` once first if `example_parity.csv` or `example_hours_plan.csv` is missing.

| Lesson | Exercise | Solution | Data |
|---|---|---|---|
| 33.1 Feasibility and the 180-hour budget | `lesson01_budget.py` | `lesson01_budget_solution.py` | `example_hours_plan.csv` (`phase,planned_h`) |
| 33.2 Project folder | `make_project.py` (complete tool, no TODO) | — | none |
| 33.2 How many repeats, how many molecules | `lesson02_sample_size.py` | `lesson02_sample_size_solution.py` | `example_parity.csv`, generated |
| 33.3 Poster figure | `lesson03_poster_figure.py` | `lesson03_poster_figure_solution.py` | `example_parity.csv`, generated |
| 33.4 Package check | `lesson04_package_check.py` | `lesson04_package_check_solution.py` | a project folder from `make_project.py` |

`example_parity.csv` is GENERATED by `make_data.py` (seed 33): 90 vibrational modes of 30 imaginary molecules, with "calculated" values 4.0 % too high plus 15 cm⁻¹ scatter. It is practice data for the figure and the sample-size study, not a real benchmark. For real data, see the project briefs in `projects/` (NIST CCCBDB, NIST WebBook, AqSolDB, the IUPAC digitized pKa dataset) and keep each source's licence in your data dictionary.

Your own project:

```bash
py lesson01_budget_solution.py 30 25 10 1.3 my_plan.csv
py make_project.py ../../../my-ir-benchmark
py lesson02_sample_size_solution.py 0.12 0.10
py lesson03_poster_figure_solution.py my_parity.csv
py lesson04_package_check_solution.py ../../../my-ir-benchmark
```

Arguments of `lesson01_budget`: number of items (molecules or samples), machine minutes per item, your attended minutes per item, rerun factor, and optionally your own plan CSV. Arguments of `lesson02_sample_size`: the standard deviation from your pilot and the 95 % half-width you want, in the same unit.
