# Instructor notes — 02.1 Functions chemists meet

- Objective: the learner can move between a curve and its linear form (log–log, ln–linear, ln k vs 1/T) and extract a constant from the slope.
- Likely confusion: when to use ln vs log10. Rule given: pH is base 10, everything from kinetics and thermodynamics is base e.
- Misconception: "Taking the log of 25 °C is fine." Logs need dimensionless numbers, and Arrhenius needs kelvin.
- Analogy: an exponential is compound interest in reverse; each equal time step removes the same fraction, not the same amount.
- Expected hands-on result: Ea ≈ 103.6 kJ/mol, A ≈ 4.9e13 1/s, k(37 °C) ≈ 1.8e-4 1/s from the seeded data (model value 103 kJ/mol).
- Extension: refit using only the three lowest temperatures and see how much Ea moves; preview of uncertainty in slopes (Module 5).
