# Instructor notes — 09.5 Titration theory and titration curves

- **Objective:** compute key points of strong- and weak-acid curves; solve the whole curve from the charge balance; choose an indicator and estimate the titration error; find the end point from pH data by derivatives; read pKa at half-equivalence.
- **Likely confusion:** end point versus equivalence point; why the half-equivalence pH equals pKa only for a weak acid (for HCl it is just 1.48).
- **Misconception:** "neutralisation means pH 7". At equivalence for a weak acid the solution is basic (quiz q2).
- **Analogy:** the curve is a road with a cliff. The indicator is a sign you put up; it must stand at the cliff edge, not in the flat valley before it.
- **Expected hands-on result:** key points 2.88 / 4.58 / 4.76 / 8.73 / 11.29; HCl 1.00 / 1.48 / 7.00 / 11.29 and 3.70 / 10.30 at ±0.10 mL. Indicator errors: methyl orange −90 %, bromothymol blue −0.57 %, phenolphthalein +0.01 %. Example data: first derivative 25.10 mL, second 25.00 mL, half-equivalence pH 4.79 (meter offset +0.03). Pencil (formic acid): pH 2.53 (exact 2.54), 3.75, 8.14.
- **Extension:** a Gran plot ($V_b \cdot 10^{-\text{pH}}$ against $V_b$ before the end point) gives the end point from the buffer region alone; or titrate a diprotic acid (citric acid) in code and find why its first two end points blur together.
- **Scope:** the simulation and the code do not train burette handling; Module 10 does the home vinegar titration project.
