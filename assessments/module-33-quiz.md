# Module 33 quiz — Research Project

This quiz checks the decisions you make in a research project without a supervisor: whether a question can be answered at home, whether it fits in 180 hours, how a study must be designed so its result can be trusted, how many repeats it needs, how to keep the data so a reader can check them, how to write the result so it is understood, and how to get and describe outside feedback honestly. It has 9 scenario questions. The pass mark is 70 %.

Review these lessons first:

- [33.1 · Choosing a question you can answer at home](../lessons/module-33/lesson-01.md)
- [33.2 · Designing the study and managing the data](../lessons/module-33/lesson-02.md)
- [33.3 · Writing the report and the poster](../lessons/module-33/lesson-03.md)
- [33.4 · Getting feedback and what comes next](../lessons/module-33/lesson-04.md)

Have a calculator ready. Useful values: Student t at 95 % (two-sided) is 3.18, 2.78, 2.45, 2.36, 2.31 and 2.26 for 3, 4, 6, 7, 8 and 9 degrees of freedom. The wrong options are the answers that common slips produce, such as forgetting the rerun factor, using the fitting error instead of a held-out error, testing groups in blocks, or claiming more than the evidence shows.
