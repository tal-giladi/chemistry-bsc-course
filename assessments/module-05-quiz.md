# Module 5 quiz — Python for Scientists

This quiz checks whether you can make the decisions a scientist makes when analysing data in Python: keeping an environment reproducible, writing array code that does what you think, fitting with honest uncertainties, reading instrument files without silent errors, and proving that a notebook's results can be repeated. It has 10 scenario questions. The pass mark is 70 %.

Review these lessons first:

- [05.1 · Python setup and the scientific stack](../lessons/module-05/lesson-01.md)
- [05.2 · Arrays, vectorised maths and plotting](../lessons/module-05/lesson-02.md)
- [05.3 · Fitting models to data with uncertainty](../lessons/module-05/lesson-03.md)
- [05.4 · Reading real instrument data](../lessons/module-05/lesson-04.md)
- [05.5 · Reproducible analysis notebooks](../lessons/module-05/lesson-05.md)

No computer is needed, but a calculator helps for two questions. The wrong options are the conclusions that common shortcuts lead to.
