# References

Free sources used throughout the course. Each lesson lists its own primary sources at the end.

## Free courses and textbooks

- MIT OpenCourseWare chemistry courses (5.111SC, 5.12, 5.13, 5.60, 5.61, 5.62, 5.07SC, 5.301, 5.310, 5.35): https://ocw.mit.edu/
- Yale Open Courses, CHEM 125 Freshman Organic Chemistry: https://oyc.yale.edu/chemistry/chem-125a
- LibreTexts Chemistry: https://chem.libretexts.org/
- OpenStax Chemistry 2e: https://openstax.org/details/books/chemistry-2e

## Data

- SDBS spectral database (AIST): https://sdbs.db.aist.go.jp/
- NIST Chemistry WebBook: https://webbook.nist.gov/chemistry/
- NIST CODATA fundamental constants: https://physics.nist.gov/cuu/Constants/
- PubChem (including GHS safety data): https://pubchem.ncbi.nlm.nih.gov/
- NMRDB prediction: https://www.nmrdb.org/
- RCSB Protein Data Bank: https://www.rcsb.org/

## Software

- Python: https://www.python.org/ (this course pins Python 3.14 and the packages in `labs/common/requirements.txt`)
- Avogadro: https://avogadro.cc/
- xtb: https://xtb-docs.readthedocs.io/
- ORCA: https://www.faccts.de/orca/
- phyphox: https://phyphox.org/
- ChemCollective virtual labs: https://chemcollective.org/vlabs
- PhET simulations: https://phet.colorado.edu/
